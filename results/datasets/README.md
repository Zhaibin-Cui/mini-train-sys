# Dataset and cache evidence

Raw biographies, profile payloads, token shards, and probe caches remain on `/data`. This
directory stores authoritative manifests, lineage, split semantics, counts, tokenizer identity,
file sizes, and SHA256 needed to bind formal runs to their inputs.

SynBioS index: [`synbios_moe/README.md`](synbios_moe/README.md). Server-only size/retention
inventory: [`../catalog/retention.json`](../catalog/retention.json).
