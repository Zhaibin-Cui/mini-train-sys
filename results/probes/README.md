# Probe experiments

This directory contains evidence derived from frozen SynBioS backbones:

- `synbios_moe/cache/`: P/Q cache manifests and lineage;
- `synbios_moe/data/`: attribute-token distribution used to define probe targets;
- `synbios_moe/{single,multi5_permute}/formal/`: formal P/Q runs and diagnostics;
- `synbios_moe/comparisons/`: matched cross-condition summaries and figures;

The canonical comparison is
[`synbios_moe/comparisons/formal_20260724/`](synbios_moe/comparisons/formal_20260724/).
Probe-capacity sweeps are performance measurements and therefore remain under
[`../benchmarks/synbios_moe/`](../benchmarks/synbios_moe/).
